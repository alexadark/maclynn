7. Claude Design, explained

Design creates visual work such as layouts, prototypes and one-page documents. Slides creates presentations. An artifact is the output you open and edit in Claude. A design system supplies shared colours, typography and visual patterns. A template supplies a starting document or layout. The brand-voice skill supplies writing instructions and must be shared separately.

Rachel’s Maclynn design system was visible as moved to Claude and marked as the default on 26 October. That does not prove that every proposal or presentation template is usable. The immediate goal is to find those templates and make one successful test from each.

8. Resolve the Design migration during the call

  1. Ask Rachel to show the original. Open the old workspace at claude.ai/design. Identify the proposal template, presentation template and any projects she needs to keep.
  2. Save a copy first. Download the offered ZIP archive and separately save any important chat instructions or comments. Chats and comments do not migrate.
  3. Check the switches. Organization settings → Artifacts: confirm Artifacts, Design, Slides and Design systems are enabled.
  4. Find the moved work. In Claude → Artifacts, open the Design menu and View design systems. Confirm the Maclynn system is available and the intended default. Look for the templates as well as the design system.
  5. Move missing work. If the migration option is available, use the review flow for the relevant project. Owners can use “Move everything” from Artifacts, including templates. Read the scope and review results before confirming; this can affect the whole organisation. Keep the tab open for a project move.
  6. Handle failures individually. Read the “Didn’t move” result. If offered, open “Fix in Claude Design Standalone”, correct the reported issue, run Check again and retry. Do not delete the working source to force a retry.
  7. Test the result. Start a fictional proposal from the intended template and a short slide deck. Check branding, editable content and export. Ask another member to open the shared result. Record which template works and which still needs repair.

The standalone site closes on 14 December 2026. Avoid making new edits to an old copy after moving it; those edits do not sync into Claude. If a template is missing, keep its ZIP and diagnose the migration result before rebuilding it.

Ask Rachel: “Can you show me the exact template you normally start from, and what you expect to see when you open it in Claude?”

9. Finish with each team member

  1. Confirm the Maclynn organisation, plugin and shared brand guidance.
  2. Connect the required apps with the correct work account and review tool permissions.
  3. Choose the work folder deliberately and review Settings → Cowork → Global instructions.
  4. Open a new task and run the fictional sales walkthrough. Keep real client sends separate from the sandbox demonstration.
  5. Test a shared Design template. Record any missing access, failed connection or template issue with the exact on-screen message.
