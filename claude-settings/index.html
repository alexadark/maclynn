4. Claude Design

Design makes branded documents and slides. Your Maclynn design system has moved into Claude. Your templates still need checking.

  1. Open the old claude.ai/design and find the proposal and slide templates you use.
  2. Download the ZIP backup first. Chats and comments don't move.
  3. In Claude, go to Artifacts → Design → View design systems. Check that Maclynn is there and set as default.
  4. Find each template. If one is missing, use "Move" on that project, then read the result.
  5. If something "Didn't move", open "Fix in Claude Design Standalone", fix it and retry.
  6. Test: make a fake proposal and a short deck. Check branding and export.

The old Design site closes on 14 December 2026.
