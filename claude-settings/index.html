4. Proposals in Claude Design

A proposal needs three pieces. Each one does one job.

Design systemThe look: colours, Quasimoda, logos, photos. Already shared with everyone and set as default.
Proposal templateThe structure: the 6-page A4 layout, page by page. It moved into Claude as plain files inside the design system. It isn't a usable template yet.
Brand voice skillThe words: tone, UK or US spelling, no prices, no network figures.

What the proposal takes from the design system

  • Colours: White Chalk and Beige Stone backgrounds, Blue Ink text, Gold Sand accents.
  • Type: Quasimoda for headings and text.
  • Logo on the cover and the closing page.
  • Photos and team portraits from the approved library only.

Turn the template into a real template

  1. Download the ZIP backup from the old claude.ai/design first.
  2. In Claude, open Design, select the Maclynn design system and open the proposal file from its files.
  3. Ask Claude Design: "Build a Maclynn proposal template from this file, using the Maclynn design system."
  4. Correct it until each page looks right, then save it as a template named "Maclynn proposal".
  5. Test: on the Design home, pick the Maclynn design system and the Maclynn proposal template, then make a proposal for a fake client. Check the layout, the tone and the PDF export.
  6. A colleague does the same test from their account.

The old Design site closes on 14 December 2026. Make no new edits there.
